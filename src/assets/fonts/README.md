# Fonts Directory

Place your custom font files here (.ttf, .otf)

## Usage:
1. Add font files to this directory
2. Update your `react-native.config.js` or `metro.config.js`
3. Run `npx react-native-asset` or link fonts manually

## Example:
- Roboto-Regular.ttf
- Roboto-Bold.ttf  
- Inter-Regular.otf
